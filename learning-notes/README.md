## 이 노트에 남길 것

- 주제마다 복습 질문 3개, 핵심 3~5개, 내가 헷갈린 부분만 남긴다.
- 답은 접어 둔다. 설명을 읽기 전에 내 말로 답한다.
- 새 기록은 기존 주제에 합치고, 같은 설명을 여러 곳에 반복하지 않는다.
- 긴 시도 과정은 아래 상세 기록에만 보관한다. 복습할 때 전부 읽지 않는다.
- 정답을 받았다는 사실과 혼자 설명할 수 있다는 사실을 구분한다.
