# 학습 기록

알고리즘 문제를 풀면서 겪은 문제점, 설계의 변화, 다시 사용할 수 있는 개념을 분리해 기록한다.

## 기록 분류

- `문제모음집`: 막힌 현상, 오류 메시지, 잘못 이해한 내용과 원인
- `설계모음집`: 최초 접근부터 디버깅을 거쳐 사고가 바뀐 과정
- `개념모음집`: 다른 문제에도 다시 적용할 수 있는 Python·자료구조·알고리즘 개념

## 작성 원칙

1. 정답보다 당시의 생각과 근거를 먼저 기록한다.
2. 실제로 확인한 사실과 아직 검증 중인 생각을 구분한다.
3. 오류 메시지는 가능한 한 그대로 남긴다.
4. 문제별 기록은 풀이 코드와 서로 연결한다.
5. 개념 문서는 여러 문제에서 재사용하고 관련 문제를 링크한다.
