# 학습 기록

부트캠프에서 제공한 문제를 직접 풀고 복습하며 기록한다. 처음에 무엇을 생각했고, 어디서 막혔으며, 무엇을 이해했는지 남긴다.

## 기록 분류

- `문제모음집`: 막힌 현상, 오류 메시지, 잘못 이해한 내용과 원인
- `설계모음집`: 최초 접근부터 디버깅을 거쳐 사고가 바뀐 과정
- `개념모음집`: 다른 문제에도 다시 적용할 수 있는 Python·자료구조·알고리즘 개념

## 작성 원칙

- 핵심부터 짧게 쓴다. 문제마다 다시 적용할 깨달음 한두 개를 고른다.
- 문제 기록은 **처음 생각 → 막힌 지점 → 이제 이해한 것**으로 남긴다.
- 직접 쓴 표현과 고민은 살리고, 기술적으로 틀린 부분만 정확하게 고친다.
- 공통 설명과 복습 질문은 개념 문서에 모으고 링크로 연결한다.
- 설계에는 접근 순서와 꼭 필요한 상태 추적만 남긴다.
- 직접 확인한 사실과 아직 확인할 내용을 구분한다.
