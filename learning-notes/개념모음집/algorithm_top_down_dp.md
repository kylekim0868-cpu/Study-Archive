# Algorithm — Top-down DP

## 학습 계기

피보나치 재귀에서 반복되는 부분 문제를 발견하고, 일반 재귀와 메모이제이션의 차이를 이해하기 위해 작성했다.

## 공통점

일반 재귀와 Top-down DP는 큰 문제를 작은 문제로 나누는 재귀 관계를 함께 사용할 수 있다.

```text
f(n) = f(n-2) + f(n-1)
```

## 차이점

일반 재귀는 같은 부분 문제를 다시 만나면 다시 계산한다. Top-down DP는 처음 계산한 결과를 저장하고, 같은 부분 문제를 다시 만나면 저장된 결과를 반환한다.

```text
부분 문제 요청
→ 저장된 결과가 있는지 확인
  → 있으면 반환
  → 없으면 계산
→ 결과 저장
→ 반환
```

## 성립에 필요한 관점

- 큰 문제의 답을 작은 문제의 답으로 구성할 수 있는가?
- 같은 작은 문제가 반복해서 등장하는가?
- 부분 문제를 구별할 key를 정할 수 있는가?
- 계산 결과를 다음 호출에서 다시 사용할 수 있는가?

## 복습 전 반드시 답할 질문

문제를 다시 풀 때 바로 구현부터 시작하지 않고 아래 질문에 먼저 답한다. 답이 바로 나오지 않는 질문을 현재 복습할 지점으로 삼는다.

- 반복해서 계산되는 작은 문제는 무엇인가?
- `dp[n]` 또는 `memo[n]`에 저장할 값의 의미는 무엇인가?
- 가장 작은 문제인 Base Case는 무엇인가?
- 이전에 계산한 결과를 이용해 현재 결과를 어떻게 만드는가?
- 하향식과 상향식 중 어떤 방향으로 접근할 것인가?
- 계산 결과를 저장하지 않으면 어떤 중복이 발생하는가?
