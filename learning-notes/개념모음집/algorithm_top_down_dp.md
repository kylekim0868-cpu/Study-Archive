# DP — 계산 결과를 저장하고 다시 쓰기

[복습 목록](../README.md)

## 먼저 답해볼 질문

- 일반 재귀와 메모이제이션은 어느 단계에서 달라질까?
- memo[n]에는 무엇이 언제 저장될까?
- 안쪽 함수가 반환한 값을 바깥 함수는 어떻게 전달할까?

<details>
<summary>막혔을 때 확인할 핵심</summary>

- 큰 문제를 작은 문제의 답으로 구성하고, 반복되는 부분 문제의 결과를 재사용한다.
- 기저 조건 확인 → 저장된 결과 조회 → 없으면 계산 → 결과 저장 → 반환.
- memo[n]에는 식 자체가 아니라 오른쪽 계산이 끝난 숫자가 저장된다.
- 재귀 호출은 같은 memo를 공유한다. 전달되지 않은 경우에만 만든다.
- 피보나치는 각 상태를 한 번 계산한다. 덧셈을 O(1)로 보는 기준에서 시간 O(n), memo와 재귀 스택 공간 O(n)이다.

</details>

## 내가 헷갈린 부분

| 처음 생각 | 다시 기억할 것 |
|---|---|
| 저장하면 중복 계산이 사라진다. | 계산 전에 저장된 값을 조회해야 한다. |
| return n이면 된다. | n은 인덱스, memo[n]은 계산 결과다. |
| 안쪽 함수가 반환했으니 바깥도 반환한다. | 바깥에서도 받은 결과를 반환해야 한다. |
| not memo면 최초 호출이다. | 빈 딕셔너리도 참이다. None 여부와 구분한다. |
| memo[2] = 1을 미리 넣어야 한다. | 0과 1의 기저 조건으로 계산할 수 있다. |

복습 예제: fib(3)에서 0·1은 바로 반환하고, 2·3의 계산 결과가 저장되는 순서를 적어보자.
