# Algorithm — Top-down DP

## 학습 계기

피보나치 재귀에서 반복되는 부분 문제를 발견하고, 일반 재귀와 메모이제이션의 차이를 이해하기 위해 작성했다.

## 공통점

일반 재귀와 Top-down DP는 큰 문제를 작은 문제로 나누는 재귀 관계를 함께 사용할 수 있다.

```text
f(n) = f(n-2) + f(n-1)
```

## 차이점

일반 재귀는 같은 부분 문제를 다시 만나면 다시 계산한다. Top-down DP는 처음 계산한 결과를 저장하고, 같은 부분 문제를 다시 만나면 저장된 결과를 반환한다.

```text
부분 문제 요청
→ 저장된 결과가 있는지 확인
  → 있으면 반환
  → 없으면 계산
→ 결과 저장
→ 반환
```

## 성립에 필요한 관점

- 큰 문제의 답을 작은 문제의 답으로 구성할 수 있는가?
- 같은 작은 문제가 반복해서 등장하는가?
- 부분 문제를 구별할 key를 정할 수 있는가?
- 계산 결과를 다음 호출에서 다시 사용할 수 있는가?
