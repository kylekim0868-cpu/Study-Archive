# Algorithm — Top-down DP

## 핵심 원리

큰 문제를 작은 문제로 나누고, 이미 계산한 결과를 저장해 재사용한다. 피보나치에서는 f(n)을 f(n-2)와 f(n-1)로 나누며 같은 작은 문제가 반복된다.

```text
기저 조건 확인
→ 저장된 결과가 있다면 반환
→ 없다면 작은 문제들을 계산
→ 결과를 저장하고 반환
```

일반 재귀와의 차이는 결과를 저장하는 것에 더해, 다시 필요할 때 조회한다는 점이다. [딕셔너리의 저장과 조회](python_딕셔너리와_메모이제이션.md)

## 복습 전 반드시 답할 질문

코드를 보지 않고 답한다. 막히는 질문부터 다시 확인한다.

- 반복해서 계산되는 작은 문제는 무엇인가?
- `dp[n]` 또는 `memo[n]`에 저장할 값의 의미는 무엇인가?
- 가장 작은 문제인 Base Case는 무엇인가?
- 이전에 계산한 결과를 이용해 현재 결과를 어떻게 만드는가?
- 하향식과 상향식 중 어떤 방향으로 접근할 것인가?
- 계산 결과를 저장하지 않으면 어떤 중복이 발생하는가?
