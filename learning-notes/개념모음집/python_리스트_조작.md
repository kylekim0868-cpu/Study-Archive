## 먼저 답해볼 질문

- 빈 리스트에 append는 되는데 selected[0] 대입은 왜 안 될까?
- append와 pop은 각각 무엇을 바꾸고 반환할까?
- selected[-1]을 읽기 전에 어떤 조건이 필요할까?

<details>
<summary>막혔을 때 확인할 핵심</summary>

- append는 새 원소를 끝에 추가한다. 빈 리스트에도 사용할 수 있다.
- 인덱스 대입은 이미 존재하는 위치의 값을 바꾼다. 빈 리스트의 0이나 -1 위치는 없다.
- append의 반환값은 None이다. pop은 원소를 제거하고 제거한 값을 반환한다.
- selected[-1]은 마지막 원소다. 비어 있으면 IndexError가 난다.
- continue는 현재 반복의 남은 작업을 건너뛰고 다음 반복으로 간다.

</details>
