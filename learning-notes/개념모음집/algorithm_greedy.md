# Algorithm — Greedy

## 학습 계기

`Greedy_미팅`에서 선택을 먼저 한 뒤 취소하는 접근과, 기준에 따라 조건을 만족하는 후보만 선택하는 접근을 비교하기 위해 작성했다.

## 확인할 개념

- 매 단계에서 선택 기준이 필요한 이유
- 지역적인 선택이 전체 목표와 연결되는 근거
- 회의 선택 문제에서 종료 시간을 기준으로 삼는 이유
- 선택된 상태를 최소한으로 유지하는 방법

## 내가 설명해 보기

학습 후 직접 설명을 작성한다. 정답 문장을 외우기보다 반례나 교환 관점으로 선택 기준을 설명할 수 있는지 확인한다.

## 복습 전 반드시 답할 질문

문제를 다시 풀 때 바로 구현부터 시작하지 않고 아래 질문에 먼저 답한다. 답이 바로 나오지 않는 질문을 현재 복습할 지점으로 삼는다.

- 현재 순간에 선택할 수 있는 최선은 무엇인가?
- 어떤 기준으로 데이터를 정렬해야 하는가?
- 현재의 선택을 나중에 번복하지 않아도 되는 이유는 무엇인가?
- 이 선택이 이후 선택의 가능성을 줄이지 않는가?
- 현재 선택 기준이 실패하는 반례는 없는가?
- 매 순간의 최선이 전체 결과의 최선으로 이어지는 근거는 무엇인가?
