# Algorithm — DFS

## 핵심 원리

DFS는 방문하지 않은 이웃을 따라 깊게 들어가고, 더 갈 곳이 없으면 돌아가 남은 이웃을 탐색한다.

- visited: 이미 방문했는지 기억하여 중복 탐색을 막는다.
- 재귀 호출 스택: 현재 호출의 상태와 돌아가 이어서 실행할 위치를 기억한다.
- 직접 만든 스택: 나중에 넣은 후보를 먼저 꺼내는 LIFO 방식으로 탐색 순서를 관리한다.

재귀에서는 이웃 확인이 끝나면 현재 함수가 반환한다. 시작 호출까지 끝나면 탐색 완료다. 반복 방식에서는 스택이 비면 끝난다. 두 경우 모두 시작점에서 도달할 수 있는 영역에 대한 완료이며, 그래프 전체와 같지 않을 수 있다.

첫 도착 경로가 최단이라는 보장은 없다. 인접 리스트와 평균 O(1) 방문 검사를 쓰면 시간은 O(V + E), 재귀 방식의 방문 기록과 호출 스택 공간은 O(V)다. 리스트로 방문 여부를 검사하면 시간 비용이 추가된다.

## 복습 전 반드시 답할 질문

코드를 보지 않고 답한다. 막히는 질문부터 다시 확인한다.

- 왜 스택 또는 재귀 함수를 사용하는가?
- `visited`와 호출 스택은 각각 무엇을 기억하는가?
- 현재 정점에서 다음 정점으로 더 깊게 들어가는 조건은 무엇인가?
- 더 이상 방문할 이웃이 없다면 현재 함수는 어떻게 되는가?
- 반복 방식의 스택이 비었다는 것은 무엇을 의미하는가?
- 목적지에 처음 도착한 경로가 최단 경로라고 할 수 있는가?
