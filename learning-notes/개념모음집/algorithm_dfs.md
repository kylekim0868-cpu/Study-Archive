# Algorithm — DFS

## 한 문장 정의

DFS는 시작 정점에서 한 방향으로 더 이상 갈 수 없을 때까지 깊게 탐색한 뒤, 직전 정점으로 돌아가 다른 경로를 확인하는 그래프 탐색 방식이다.

## 필요한 자료

```text
visited    → 이미 방문한 정점을 다시 탐색하지 않기 위한 기록
호출 스택  → 직전 정점으로 돌아가 남은 탐색을 이어가기 위한 기록
```

## 재귀 흐름

```text
현재 정점 방문 처리
→ 현재 정점의 이웃 확인
→ 미방문 이웃으로 재귀 호출
→ 방문할 이웃이 없다면 현재 함수 종료
→ 호출 스택을 통해 직전 함수로 복귀
→ 모든 호출이 끝날 때까지 반복
```

## `visited`와 호출 스택의 차이

처음에는 방문 기록이 있으니 끝 노드에서 직전 노드로 돌아갈 수 있다고 생각했다. 하지만 `visited`에는 어디를 방문했는지만 들어 있고, 어디로 돌아가야 하는지는 담겨 있지 않다.

```text
visited   → 이 정점을 전에 방문했는가?
호출 스택 → 어느 함수의 실행을 다시 이어가야 하는가?
```

따라서 `visited`는 중복 방문과 무한 반복을 막는다. 직전 노드로 돌아가는 과정은 재귀의 호출 스택이 담당한다.

## 종료에 대한 이해

DFS는 방문 기록에 데이터가 가득 차서 종료되는 것이 아니다. 현재 정점에서 방문하지 않은 이웃이 없다면 현재 함수가 종료되고, 호출 스택에 저장된 직전 함수로 돌아간다. 이런 식으로 모든 재귀 호출이 끝나 호출 스택이 비면 시작 정점과 연결된 영역의 탐색이 완료된다.

그래프가 여러 덩어리로 끊겨 있다면 한 번의 DFS로 그래프 전체를 방문한 것은 아니다. 시작 정점에서 도달할 수 있는 영역만 모두 방문한 상태다.

## 복잡도

- 각 정점을 최대 한 번 방문: `O(V)`
- 각 간선을 확인: `O(E)`
- 전체 시간복잡도: `O(V + E)`
- 방문 기록과 호출 스택에 필요한 공간: 보통 `O(V)`

## 복습 전 반드시 답할 질문

문제를 다시 풀 때 바로 구현부터 시작하지 않고 아래 질문에 먼저 답한다. 답이 바로 나오지 않는 질문을 현재 복습할 지점으로 삼는다.

- 왜 스택 또는 재귀 함수를 사용하는가?
- `visited`와 호출 스택은 각각 무엇을 기억하는가?
- 현재 정점에서 다음 정점으로 더 깊게 들어가는 조건은 무엇인가?
- 더 이상 방문할 이웃이 없다면 현재 함수는 어떻게 되는가?
- 반복 방식의 스택이 비었다는 것은 무엇을 의미하는가?
- 목적지에 처음 도착한 경로가 최단 경로라고 할 수 있는가?
