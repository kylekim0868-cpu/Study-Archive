# DFS — 한 방향으로 깊게 탐색

[복습 목록](../README.md)

## 먼저 답해볼 질문

- 재귀 호출 하나가 맡은 일과 멈추는 조건은 무엇일까?
- 더 갈 곳이 없으면 어디로 돌아갈까? visited가 돌아갈 위치도 기억할까?
- Flood Fill에서 좌표는 바뀌는데 원래 색은 왜 유지해야 할까?

<details>
<summary>막혔을 때 확인할 핵심</summary>

- 현재 정점을 방문 처리하고, 미방문 이웃으로 깊게 들어간다.
- 호출이 끝나면 자신을 호출한 함수로 돌아가 남은 이웃을 확인한다. 돌아갈 위치는 호출 스택이 기억한다.
- visited는 중복 탐색을 막는다. 한 번의 DFS는 시작점에서 도달 가능한 영역을 탐색한다.
- 재귀 설계는 ‘한 호출의 역할 → 전달할 정보 → 종료 조건’부터 정한다. 중첩 함수는 필수가 아니다.
- 인접 리스트와 평균 O(1) 방문 검사 기준 시간 O(V + E), 방문 기록·스택 공간 O(V). 최단 경로는 보장하지 않는다.

</details>

## 내가 헷갈린 부분

| 처음 생각 | 다시 기억할 것 |
|---|---|
| graph를 순회하면 키와 값이 나온다. | 키만 나온다. graph[start]를 순회하면 이웃 정점이 하나씩 나온다. |
| 이웃을 호출하는 쪽에서도 방문 기록을 추가한다. | 호출된 함수가 방문 처리한다면 호출자는 미방문 여부만 확인한다. |
| 재귀니까 주어진 함수를 그대로 다시 호출한다. | 다음 호출에 필요한 정보를 유지할 수 있는지 먼저 확인한다. |

## Flood Fill 한 줄 설계

범위 확인 → 처음 색과 같은지 확인 → 새 색으로 칠하기 → 상하좌우 탐색.

- 좌표는 이동하고 origin은 처음 값으로 유지한다. 이미지 접근 전에 범위를 검사한다.
- 색칠이 방문 표시다. 처음 색과 새 색이 같으면 시작 전에 이미지를 반환한다.
- DFS를 정의한 뒤 시작 좌표로 한 번 호출해야 탐색이 시작된다.
