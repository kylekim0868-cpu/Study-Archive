# Algorithm — BFS

## 한 문장 정의

BFS는 시작 정점에서 가까운 정점부터 차례대로 방문하는 그래프 탐색 방식이다.

## 필요한 자료

```text
queue   : 앞으로 탐색할 정점
visited : 이미 발견한 정점
```

## 핵심 흐름

```text
시작 정점을 큐에 넣고 방문 처리
→ 큐의 맨 앞 정점을 꺼냄
→ 그 정점의 이웃을 확인
→ 방문하지 않은 이웃을 방문 처리 후 큐 뒤에 추가
→ 큐가 빌 때까지 반복
```

## 왜 큐를 사용하는가

큐는 먼저 들어온 정점을 먼저 꺼내는 FIFO 구조다. 시작점에서 먼저 발견된 이웃을 먼저 처리하므로, BFS는 거리 1의 정점을 처리한 뒤 거리 2의 정점으로 이동한다.

## 방문 처리 시점

이웃을 큐에 넣는 순간 `visited`에 기록한다. 꺼낼 때까지 미루면 서로 다른 정점이 같은 이웃을 큐에 중복으로 넣을 수 있다.

## Python에서 기억할 것

```python
from collections import deque

queue = deque([start])
current = queue.popleft()
queue.append(neigh)
```

`deque.popleft()`는 큐의 맨 앞 원소를 `O(1)`에 꺼낸다. 일반 리스트의 `pop(0)`은 뒤 원소를 앞으로 옮겨야 하므로 `O(n)`이다.

## 언제 떠올릴까

- 시작점에서 가까운 순서가 필요한 경우
- 간선 비용이 모두 같을 때 최소 이동 횟수를 구하는 경우
- 한 단계씩 퍼지는 과정, 예: 전염·네트워크 전파를 모델링하는 경우
