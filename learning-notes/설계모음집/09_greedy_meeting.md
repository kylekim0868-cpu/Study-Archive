# Greedy 미팅 — 설계 기록

## 목표와 선택 기준

겹치지 않는 회의를 최대한 많이 선택한다. 종료 시간이 빠른 회의부터 확인하여 다음 회의를 위한 시간을 확보한다.

## 접근 순서

1. 종료 시간 기준으로 정렬한다.
2. 회의를 하나씩 꺼내 시작·종료 시간을 확인한다.
3. 아직 선택한 회의가 없다면 첫 회의를 선택한다.
4. 현재 회의가 마지막으로 선택한 회의 이후에 시작하면 추가한다.
5. 선택한 회의의 개수를 반환한다.

## 경계 조건

- 빈 입력이면 선택한 회의도 없다.
- 끝나는 시각과 시작 시각이 같아도 허용한다면 등호를 포함한다.
- 길이가 0인 회의가 허용되는 문제라면 종료 시간이 같을 때의 정렬 기준도 확인한다.

일단 추가한 뒤 취소하는 방법에서, 조건에 맞을 때만 추가하는 방법으로 바꿨다. 무엇을 선택할지 먼저 정하니 리스트 조작의 목적도 분명해졌다.
