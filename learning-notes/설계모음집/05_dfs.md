# DFS — 설계 기록

[풀이 코드](../../week3/1.%20basic/05_dfs.py) · [문제점](../문제모음집/05_dfs.md) · [개념과 복습 질문](../개념모음집/algorithm_dfs.md)

## 재귀 방식

1. 최초 호출에서 빈 방문 기록을 만든다.
2. 현재 정점을 기록한다.
3. 현재 정점의 미방문 이웃으로 재귀 호출한다. 같은 방문 기록을 전달한다.
4. 모든 이웃을 확인하면 현재 호출이 끝난다.
5. 호출했던 위치로 돌아가 남은 이웃을 확인한다.

## 스택 방식

1. 스택에 시작 정점 하나를 넣는다.
2. 맨 위 정점을 꺼낸다.
3. 이미 방문했다면 이번 반복을 건너뛴다.
4. 처음 방문했다면 기록하고 미방문 이웃을 스택에 넣는다.
5. 스택이 빌 때까지 반복한다.

## 손으로 확인할 지점

```text
0의 이웃을 1 → 2 순서로 넣음
stack = [1, 2]
다음에 꺼내는 정점 = 2
```

마지막에 넣은 정점이 먼저 나온다. 또한 꺼낼 때 방문 처리하는 방식에서는 같은 후보가 스택에 중복으로 들어갈 수 있다. 그래서 꺼낸 정점의 방문 여부부터 확인해야 한다.
