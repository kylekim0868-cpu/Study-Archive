# DP 피보나치 — 설계 기록

[풀이 코드](../../week3/1.%20basic/06_dp_fibonacci.py) · [문제점](../문제모음집/06_dp_fibonacci.md) · [개념과 복습 질문](../개념모음집/algorithm_top_down_dp.md)

## 현재 설계

1. 최초 호출에서 memo를 만들고 이후 호출에 같은 기록을 전달한다.
2. n이 0이나 1이면 기저 조건의 값을 반환한다.
3. 이미 계산한 n이면 memo[n]을 반환한다.
4. 없다면 n-2와 n-1의 결과를 구해 더한다.
5. 계산이 끝난 값을 memo[n]에 저장하고 반환한다.

## 손으로 추적한 저장 순서

n-2를 먼저 호출하는 방식으로 f(5)를 계산한 기록이다.

```text
memo[2] = 1
memo[3] = 2
memo[4] = 3
memo[5] = 5
```

기저 조건에서 바로 반환하는 0과 1은 이 설계에서는 memo에 저장되지 않는다. return을 만나면 그 호출의 아래 코드는 실행하지 않는다.
