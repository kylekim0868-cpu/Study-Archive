# BFS — 설계 기록

[풀이 코드](../../week3/1.%20basic/04_bfs.py) · [문제점](../문제모음집/04_bfs.md) · [개념과 복습 질문](../개념모음집/algorithm_bfs.md)

## 탐색 순서

1. 시작점을 큐에 넣고 발견한 정점으로 기록한다.
2. 큐 앞에서 current를 꺼낸다.
3. graph[current]에서 아직 발견하지 않은 이웃을 찾는다.
4. 이웃을 방문 기록과 큐 뒤에 추가한다.
5. 큐가 빌 때까지 반복한다.

## 손으로 확인한 상태

0의 이웃은 1과 2, 2의 이웃에는 3이 있다. 간선은 양방향이다.

| 처리한 정점 | 처리 후 queue | visited |
|---|---|---|
| 시작 전 | [0] | [0] |
| 0 | [1, 2] | [0, 1, 2] |
| 1 | [2] | [0, 1, 2] |
| 2 | [3] | [0, 1, 2, 3] |
| 3 | [] | [0, 1, 2, 3] |

큐에서 꺼내는 것만 생각하면 안 된다. 꺼낸 정점에서 다음 후보를 찾아 다시 넣는 과정까지가 한 번의 반복이다.
